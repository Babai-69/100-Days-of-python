# Day 02 – Python Loops & Basic Mathematics

This folder contains beginner-friendly Python programs created as part of my **100 Days of Python Challenge**.

## 📝 Questions Completed

### Q1. Multiplication Table
- Takes a number as input from the user.
- Generates its multiplication table from 1 to 10.
- Uses a `for` loop to display the results.

### Q2. Sum of Natural Numbers
- Takes a positive integer from the user.
- Calculates the sum of natural numbers from 1 to the entered number.
- Implements two different approaches:
  - **Mathematical Formula:** `n * (n + 1) // 2`
  - **For Loop:** Adds each natural number using an accumulator variable.

## 🛠️ Python Concepts Practised

- Variables and Data Types
- User Input (`input()`)
- Type Conversion (`int()`)
- For Loops (`for`)
- Conditional Statements (`if-else`)
- Range Function (`range()`)
- Arithmetic Operators (`+`, `*`, `//`)

## ▶️ How to Run

Make sure Python is installed on your system.

Run the programs using:

```bash
python multiplication table.py
```

```bash
python sum of natural numbers.py
```

## 🎯 Learning Objective

The goal of Day 02 was to understand how Python loops work and how mathematical problems can be solved using both formulas and iterative approaches.
