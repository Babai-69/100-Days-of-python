## 🎯 Practice Questions

### Rotate a List
- Created a list containing multiple numbers.
- Took the number of rotation positions as input from the user.
- Rotated the list to the right by the specified number of positions.
- Maintained the correct order of elements after rotation.
- Avoided using list slicing and external libraries.

### Move All Zeros to the End
- Created a list containing positive numbers, negative numbers, and zeros.
- Identified all zero elements in the list.
- Moved all zeros to the end of the list.
- Maintained the original order of all non-zero elements.
- Avoided using `sort()` and `sorted()`.
