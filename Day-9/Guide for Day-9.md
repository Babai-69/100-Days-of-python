## Challenges

### Q1. Basic Password Generator
**File:** `password_generator.py`

**Objective:** Create a program that generates a random password based on the length entered by the user.

**Requirements:**
- Ask the user to enter the desired password length.
- Include uppercase letters, lowercase letters, numbers, and special characters.
- Use Python's `random` module to select characters.
- Display the generated password.
- Do not accept a password length smaller than 4.

**Example:**
```text
Enter password length: 12
Generated Password: A7@kP2#mQ9$x
```

**Concepts:** Functions, loops, `random`, `string`, and user input.

### Q2. Shopping Bill Calculator
**File:** `shopping_bill_calculator.py`

**Objective:** Create a program that calculates a customer's total shopping bill.

**Requirements:**
- Ask the user to enter the price and quantity of each item.
- Allow the user to add multiple items.
- Calculate the total price of all items.
- Apply a 10% discount if the subtotal exceeds ₹1,000.
- Display the subtotal, discount, and final bill.

**Example:**
```text
Enter item price: 500
Enter quantity: 3

Subtotal: ₹1500
Discount: ₹150
Final Bill: ₹1350
```

**Concepts:** Functions, loops, conditional statements, arithmetic operations, and user input.
