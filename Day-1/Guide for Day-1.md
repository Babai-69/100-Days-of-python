# 🔐 Python Login System

A basic Python login system created as part of my **100 Days of Python** challenge.

## 📌 About the Project

This program allows users to log in using a predefined username and password. After successful login, users can also change their username or password through a simple interactive menu.

## ⚙️ Features

- **Username Validation:** Keeps asking until the correct username is entered.
- **Password Validation:** Keeps asking until the correct password is entered.
- **Change Username:** Allows users to update their existing username.
- **Change Password:** Allows users to update their existing password.
- **Interactive Menu:** Lets users choose what action they want to perform.
- **Exit Option:** Allows users to exit the program.

## 🧠 Python Concepts Used

- Variables
- Data Types and Strings
- `input()` and `print()`
- `while` loops
- `if-elif-else` statements
- `break` statement
- Variable reassignment

## ▶️ How to Run

1. Make sure Python is installed on your system.
2. Download or clone this repository.
3. Open the project folder in VS Code or any Python IDE.
4. Run the following command:

```bash
python login_system.py
```

5. Enter the predefined login credentials to access the menu.

## 🎯 Learning Objective

The main objective of this project is to understand how Python handles user input, conditional statements, loops, and variable updates through a simple real-world example. It is a learning script, not a secure authentication system. It stores passwords in plain text and displays them in the terminal. That's perfectly fine for practising Python basics, but avoid using this approach for real accounts.
