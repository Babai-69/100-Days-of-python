## Challenges

### 1. Factorial Calculator

**File:** `factorial_calculator.py`

**Objective:**

- Accept an integer from the user.
- Calculate the factorial using a loop inside a function.
- Return the final result.
- Handle negative numbers.
- Remember that the factorial of 0 is 1.

**Example:**

For input `5`:

5! = 5 × 4 × 3 × 2 × 1 = 120

**Test Cases:**

| Input | Expected Output |
|---|---|
| 0 | 1 |
| 1 | 1 |
| 4 | 24 |
| 5 | 120 |
| -5 | Invalid Input |

**Concepts:** Functions, loops, multiplication, conditional statements.

---

### 2. Prime Number Checker

**File:** `prime_number_checker.py`

**Objective:**

- Accept an integer from the user.
- Create a function to check whether the number is prime.
- A prime number has exactly two factors: 1 and itself.
- Return `True` if the number is prime.
- Return `False` otherwise.
- Handle numbers less than or equal to 1.

**Test Cases:**

| Input | Expected Output |
|---|---|
| 2 | True |
| 3 | True |
| 7 | True |
| 10 | False |
| 1 | False |
| 0 | False |
| -5 | False |

**Concepts:** Functions, loops, conditional statements, modulus operator (`%`).
